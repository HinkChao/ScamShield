01 / Our mission

Security findings people can understand.

Rather than an opaque verdict, ScamShield aims to show observable warning signs, explain uncertainty, and suggest safe verification steps.

01

Text signals

Identify urgency, credential requests, and suspicious financial pressure. Signals are clues, not proof.

02

Safe URL inspection

Analyze suspicious links as text without opening or fetching submitted destinations.

03

Explainable guidance

Ground explanations in evidence and communicate uncertainty in readable language.

04 / How to contribute

Start here, then build together.

  1. Pick a GitHub IssueRead its acceptance criteria. Confirm ownership and a reviewer with the team.
  2. Work in a feature branchClone the repo or use Colab; never make unreviewed changes directly to main.
  3. Keep your module contract compatibleConfirm inputs and outputs with the UI, risk, security, and ML contributors.
  4. Test, then open a pull requestInclude reproduction steps, tests, limitations, and the Issue number. Ask a teammate to review.
  5. Integrate and demonstrateMerge reviewed work, run an end-to-end test, and record remaining gaps honestly.
